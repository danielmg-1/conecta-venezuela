# Contribuir a Conecta Venezuela

¡Gracias por tu interés en aportar! Este proyecto existe para ayudar a las
personas afectadas por desastres en Venezuela, y toda contribución cuenta.

## Licencia de las contribuciones

Al enviar un pull request, aceptas que tu aporte se distribuye bajo la misma
licencia del proyecto: **GNU AGPL-3.0**.

## Developer Certificate of Origin (DCO)

Cada commit debe estar firmado con `Signed-off-by` para certificar que tienes
derecho a aportar ese código. Esto se hace agregando `-s` a tu commit:

```bash
git commit -s -m "Tu mensaje"
```

Esto agrega automáticamente una línea como:

```
Signed-off-by: Tu Nombre <tu@email.com>
```

Al firmar, certificas el [Developer Certificate of Origin v1.1](https://developercertificate.org/):
que el código es tuyo o tienes derecho a aportarlo bajo la licencia del proyecto.

## Cómo contribuir

1. Haz un fork del repositorio.
2. Crea una rama descriptiva: `git checkout -b fix/nombre-del-cambio`.
3. Haz tus cambios siguiendo el estilo del proyecto.
4. Commitea con `-s` (DCO).
5. Abre un Pull Request explicando qué cambia y por qué.

## Reportar problemas o vulnerabilidades

- **Bugs y mejoras:** abre un Issue en GitHub.
- **Vulnerabilidades de seguridad:** reportar en privado a
  angel.daguier.ortiz@gmail.com, **no abrir issue público**.

## Código de conducta

Sé respetuoso. Este es un proyecto humanitario; mantengamos el foco en ayudar.
